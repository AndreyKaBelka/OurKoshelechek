## Открытые баги
- **Кнопка «Партнёр» без партнёра.** Если в группе нет второго участника, кнопка всё равно
  активна и молча записывает плательщиком текущего пользователя
  (`partner?.userId ?? currentUserId` в `TransactionsScreen.tsx`; то же в режиме «Вместе»
  и в переводах). Нужно решение владельца: блокировать/скрывать или предупреждать.

## Бэклог (по приоритету)
1. **Изображения для целей и категорий** — загрузка, показ в карточках/списках; эмодзи
   остаётся fallback. Хранилища файлов в проекте пока нет — сначала спроектировать.
2. Редактирование названия/иконки категории (сейчас инлайн только лимит) — если понадобится.
3. Техдолг из code review:
   - `internal/service/*` работает с `graph/model` вместо доменных типов — большой
     рефакторинг, делать по одному сервису за раз, с ревью;
   - N+1 в `transaction.List`, `group.loadGroupModel`, списках целей;
   - `ErrNotFound` непоследовательно переводится в GraphQL-ошибку (`Update`/`Delete`).
4. Фильтры истории по категории/участнику/датам в UI (API уже умеет).
