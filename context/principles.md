# Принципы и инварианты

Читать всегда. Это то, что нельзя нарушать без явного решения владельца.
Подробности устройства слоёв — `architecture.md`.

## Архитектура
1. **Schema-first.** Контракт — `api/**/*.graphql`. `graph/generated.go` и
   `graph/model/models_gen.go` руками не править — только `make generate`.
2. **Сервисный слой обязателен.** Вся бизнес-логика — `internal/service/<domain>.go`.
   Резолвер = вызов сервиса (+ `platform.CurrentUserID(ctx)`) + mapper. Резолверы не трогают
   `r.Repos.*`/`r.UoW`; исключение — только директивы в `resolvers/directives.go`.
3. **Только конструкторы.** Доменные структуры создаются через `New<Entity>(...)`, в том
   числе в `internal/mapper` (`ToDomain*` возвращает `error` конструктора). Литерал
   структуры вне её пакета = обход валидации.
4. **Репозитории** — pgx без ORM, принимают `platform.DBTX`, `pgx.ErrNoRows` → `ErrNotFound`
   пакета. Несколько репозиториев в одной операции — через `repository.RunInTx`.
5. **Проверки до записи.** Принадлежность к группе (`requireGroupMember`, категория той же
   группы) проверяется **до** `RunInTx`, а не после commit. FK в БД не гарантирует, что
   сущность из той же группы.
6. **Авторизация** — директивы `@requireGroupMembership` (чтение) и
   `@requireGroupRole(min: …)` (изменения) на каждом поле с `groupId`. Любой `userId` из
   инпута дополнительно проверяется на членство в группе в сервисе.

## Данные
7. **Деньги — целые копейки** (`int64`, `Money`/`MoneyInput`), никаких float. На фронте
   конвертация только через `src/lib/money.ts`.
8. **ID — UUIDv7** через `platform.NewID()` (сортировка по времени; на этом держится порядок
   истории внутри дня).
9. **История неприкосновенна.** Никаких `ON DELETE CASCADE` на транзакции; при удалении
   справочника — отвязка (`SET NULL`).
10. **Схема БД меняется только новой goose-миграцией**; уже выпущенные миграции не править
    (прод накатывает `migrate up` на каждом деплое). Up и Down обязательны.
11. Длина строк — в рунах (`utf8.RuneCountInString`), не в байтах: всё на кириллице.

## Продукт
12. Доход без категории; бюджет — план расходов, не зависит от дохода (см.
    `product-and-users.md`). Не возвращать «проценты от дохода» и плановый доход.
13. Не придумывать новые поля/API/constraints, если похожее уже есть в коде.

## Безопасность
14. `JWT_SECRET` обязателен вне локальной разработки. Refresh-токены хранятся только как
    SHA-256 хэш и одноразовые. Ошибки аутентификации — `extensions.code = "UNAUTHENTICATED"`.
15. Сырые ошибки БД наружу не отдавать — транслировать в sentinel (`23505` → `Err…Taken`).
