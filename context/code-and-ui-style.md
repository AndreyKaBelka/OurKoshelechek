# Стиль кода и UI

Читать при написании кода и UI-текстов. Главное правило — писать как окружающий код.

## Go
- При разработке опирайся на Uber Go style Guide - https://github.com/uber-go/guide/tree/master
- `gofmt`, `go vet`, golangci-lint по умолчанию (`.golangci.yml` нет).
- Ошибки — sentinel-переменные на уровне пакета с doc-комментарием, что и когда их
  возвращает: `var ErrNameTooLong = errors.New("category name too long")`.
  Текст ошибки — английский, со строчной буквы.
- Оборачивание — `fmt.Errorf("<действие>: %w", err)` с коротким глаголом
  (`create category`, `load category`, `get or create savings category`).
- Конструкторы `New<Entity>(id, groupID, …, createdAt, updatedAt *time.Time) (*T, error)`;
  опциональные поля — указатели, `lo.FromPtr` для разворачивания.
- Длина строк — `utf8.RuneCountInString`.
- Комментарии — английские, объясняют «почему» (гонки, атомарность, неочевидные решения),
  а не пересказывают код. Комментарии в SQL-миграциях — по-русски.
- Тесты — рядом (`*_test.go`), в основном на доменные конструкторы и директивы.

## Frontend (TypeScript/React)
- Двойные кавычки, функциональные компоненты `export function XScreen()`.
- Данные — только через сгенерированные хуки из `*.generated.ts`
  (`useGoalsQuery`, `useContributeToGoalMutation`); руками gql-строки не писать.
- Инвалидация кэша urql — через `context = { additionalTypenames: [...] }`, объявленный
  константой вверху файла.
- Деньги — `formatMoney`/`formatSigned`/`parseRoubleInput`/`kopecksToRoubleInput` из
  `src/lib/money.ts`; периоды — `src/lib/period.ts`; иконки — `src/lib/icons.tsx`.
- Стили — обычный CSS в `src/styles/global.css` и `src/styles/ui.css`, без CSS-in-JS.
- Линтер — oxlint (`npm run lint`), проверка типов — `npm run build` (`tsc -b`).

## UI-тексты
- Интерфейс полностью на русском, обращение на «вы» в подсказках и ошибках
  («Введите имя пользователя», «Пароль должен быть не короче 4 символов»).
- Кнопки — глагол в инфинитиве: «Создать», «Войти», «Пополнить», «Сохранить категорию».
- Состояние загрузки — «Подождите…», «Создание…».
- Плейсхолдеры с примером: «Например, Продукты», «Например, 15000».
- Суммы — рубли без копеек с неразрывными пробелами (`30 000 ₽`), знак минуса — `−`
  (U+2212), не дефис.
- Эмодзи — иконки категорий и целей (fallback, если нет изображения).
- Второй участник в UI — «Партнёр», режим разделения — «Вместе».
